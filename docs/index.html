無料で始める SDK を見る
send-email.ts 
import { Relay } from '@apptalenthub/talentmail'

const client = new Relay('tm_live_xxxx')

await client.send({
  to: 'user@example.com',
  template: 'welcome',
  variables: { name: 'Tsubasa' }
})

必要な機能を、すべて内蔵

メール配信に必要なすべてをワンプラットフォームで提供

マルチプロバイダー

SMTP・SendGrid・Amazon SES を組織ごとに設定。プロバイダーロックインなし、いつでも切替可能。

テンプレートエンジン

HTMLテンプレートを管理画面で作成。{{variable}} プレースホルダーで動的コンテンツを挿入。

開封・クリック追跡

開封率・クリック率をリアルタイム計測。透明ピクセルとリンクリダイレクトで自動追跡。

マルチテナント

組織ごとに完全分離。メンバー招待、ロール制御、APIキーもすべて組織スコープ。

一斉配信

オーディエンス指定のバッチ送信・スケジュール配信。コンタクト管理とCSVインポートに対応。

ドメイン認証

独自ドメインのDNS TXTレコード検証。送信アドレスを自社ドメインで管理し、配信到達率を向上。

SDK ですぐに統合

@apptalenthub/talentmail パッケージをインストールして、 APIキーを設定するだけ。テンプレート送信、ダイレクト送信、一斉配信をコードから操作できます。

TypeScript ファースト — 完全な型定義で安全に開発

REST API — SDK なしでも HTTP リクエストで操作可能

Webhook — 送信成功・失敗イベントをリアルタイム通知
